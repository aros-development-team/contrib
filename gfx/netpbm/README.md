# Netpbm tools

This directory provides an AROS contrib build for a small subset of Netpbm 10.26.53.

The build fetches the upstream Netpbm sources, applies the included AROS patch, and builds two developer tools:

- `pngtopnm` — converts PNG images to portable anymap formats.
- `ppmtoilbm` — converts PPM images to ILBM.
