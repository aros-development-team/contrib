# MystiCube

MystiCube is a Workbench toy and `guigfx.library` demonstration. It opens a scalable window with a rotating, texture-mapped cube; pictures can be dragged onto the cube faces for display.

It loads pictures through `datatypes.library`, supports high- and truecolor screens, and can display a frames-per-second counter with the `t` key.

See `MystiCube.doc` for the original documentation.
