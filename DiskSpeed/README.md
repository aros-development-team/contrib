# DiskSpeed / ScsiSpeed

DiskSpeed and ScsiSpeed are AROS implementations of Michael Sinz's disk performance tools.

DiskSpeed measures filesystem and disk performance with configurable buffer sizes, memory types and alignment tests. ScsiSpeed measures sustained raw device read performance using low-level device I/O, without filesystem overhead.

Both tools can be started from the CLI or Workbench. ScsiSpeed performs read-only tests and can also be used with devices such as CD-ROM drives.

See `DiskSpeed.doc` for options and detailed usage.
